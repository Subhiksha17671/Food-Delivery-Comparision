# 🍔 Bite the Bill

### Food Delivery Price Comparison Website

**Bite the Bill** is a web application that helps users search for food items and compare their listed prices across different food platforms in Bengaluru.

## ✨ Features

* 🔍 Search for food items.
* 💰 Compare prices across platforms.
* 🏆 Identify the lowest listed price.
* 🍕 Browse food platforms and categories.
* 📊 Display matching food items and their prices.
* 🎨 Simple, responsive, food-themed interface.

## 🛠️ Technologies Used

* Python
* Flask
* MySQL
* HTML
* CSS
* JavaScript

## ⚙️ Requirements

* Python
* Flask
* MySQL Server
* MySQL Workbench
* Python packages: `flask`, `mysql-connector-python`, `python-dotenv`

## 🚀 How to Run

1. Clone or download this repository.

2. Install the required packages:

   ```bash
   py -m pip install flask mysql-connector-python python-dotenv
   ```

3. Create the MySQL database named `bite_the_bill`.

4. Configure your MySQL connection details using a local `.env` file.

5. Start the application:

   ```bash
   py app.py
   ```

6. Open `http://127.0.0.1:5000` in your browser.

## 🔐 Security

* Database credentials should be stored in a local `.env` file.
* The `.env` file must not be uploaded to GitHub.

## ⚠️ Note

The food prices currently stored in the database are sample prices for demonstration purposes. They are not live prices from food delivery platforms.
